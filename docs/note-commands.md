# ノート用コマンド

このフォーク (oto-lab/devuloper-posts) では、ノートの本文に `%%コマンド ...%%` と書くと、投稿するときにサーバーがその部分を結果に置き換えます。サイコロを振ったり、グラフや QR コードの画像を添付したりできます。

サーバー側で処理するので、Web 版だけでなく、スマホアプリなどほかのクライアントから投稿しても使えます。結果は普通のテキストや添付画像になるので、ほかのサーバーのユーザーにも同じように見えます。

Web 版では、投稿フォームの下にあるノート用コマンドのボタン (ターミナルのアイコン) から、入力欄を埋めるだけでコマンドを入れられます。投稿前に結果をプレビューすることもできます。

## 書き方

```
%%コマンド%%
%%コマンド メイン引数%%
%%コマンド key:value メイン引数%%
%%コマンド.サブコマンド メイン引数%%
```

- コマンドのあとにスペースを空けて引数を書きます。オプションは `key:value` の形で、メイン引数より前に書きます
- 値を複数並べるときは `|` で区切ります (例: `A|B|C`)
- 全角の `％％`、`：`、`｜`、全角スペースも使えるので、日本語入力のままでも書けます
- コードブロックやインラインコード (`` ` `` で囲んだ部分) の中は処理しません
- 知らないコマンド名はそのまま残ります
- 本文にそのまま `%%` と書きたいときは `\%\%` と書きます

書き方を間違えたり、処理に失敗したりしたときは、投稿されずにエラーの理由が表示されます。

1 つのノートに書けるコマンドは 10 個までです。結果を入れた本文が 3000 文字を超えるとき、添付ファイルが合計 16 個を超えるときも投稿できません。

## テキストを入れるコマンド

### サイコロとランダム

| 書き方 | 結果の例 |
| --- | --- |
| `%%rand.dice 2d6%%` | 🎲 2d6: 3 + 5 = 8 |
| `%%rand.choose ラーメン\|カレー\|寿司%%` | 🎯 カレー |
| `%%rand.choose count:2 A\|B\|C%%` | 🎯 C、A |
| `%%rand.num 1\|100%%` | 🔢 1〜100: 42 |
| `%%rand.omikuji%%` | ⛩️ おみくじ: 大吉 |

- `rand.dice` は `2d6` (個数 d 面数) の形で書きます。省略すると `1d6` です。サイコロは 100 個、1000 面まで
- `rand.num` は省略すると `1|100` です
- 結果は投稿するときにサーバーが決めるので、投稿したあとに選び直すことはできません

### 装飾文字

英字と数字を Unicode の装飾文字に変えます。MFM の太字などと違い、ほかのサーバーでもそのまま見えます。日本語など変換できない文字はそのまま残ります。読み上げソフトでは読みにくくなるので、使いすぎに気をつけてください。

| 書き方 | 結果 |
| --- | --- |
| `%%font.bold Hello%%` | 𝐇𝐞𝐥𝐥𝐨 |
| `%%font.italic Hello%%` | 𝐻𝑒𝑙𝑙𝑜 |
| `%%font.bolditalic Hello%%` | 𝑯𝒆𝒍𝒍𝒐 |
| `%%font.script Hello%%` | 𝓗𝓮𝓵𝓵𝓸 |
| `%%font.fraktur Hello%%` | ℌ𝔢𝔩𝔩𝔬 |
| `%%font.double Hello%%` | ℍ𝕖𝕝𝕝𝕠 |
| `%%font.sans Hello%%` | 𝖧𝖾𝗅𝗅𝗈 |
| `%%font.mono Hello%%` | 𝙷𝚎𝚕𝚕𝚘 |
| `%%font.circle Hello%%` | Ⓗⓔⓛⓛⓞ |
| `%%font.flip Hello%%` | ollǝH |

### アスキーアート

```
%%banner Hello%%
%%banner font:slant Hello%%
```

文字を大きなアスキーアートにして、コードブロックとして入れます。使えるのは半角の英数字と記号で、4 行まで書けます。スマホで崩れないように、横幅は 48 文字までです。

- `font:` フォント。`standard` (既定)、`slant`、`small`、`big`、`mini`、`shadow`

### プログレスバー

```
%%progress 7|10%%            → ▓▓▓▓▓▓▓░░░ 7/10 (70%)
%%progress 70%%              → ▓▓▓▓▓▓▓░░░ 70%
%%progress width:5 style:circle 3|5%%
```

値が 1 つのときはパーセントとして扱います。`7/10` のように `/` で区切ることもできます。

- `width:` バーの長さ (1 から 50、既定は 10)
- `style:` 見た目。`block` (▓░、既定)、`bar` (█░)、`circle` (●○)、`square` (■□)、`emoji` (🟩⬜)

### 計算

```
%%calc 1200*1.1%%            → 1200*1.1 = 1320
%%calc result:only 1200*1.1%%  → 1320
%%calc digits:2 10/3%%       → 10/3 = 3.33
```

`+ - * / % ^`、括弧、`sqrt` `abs` `round` `floor` `ceil` `sin` `cos` `tan` `log` `ln` `exp` `min` `max` などの関数と、`pi`、`e` が使えます。`×` と `÷` も使えます。

- `result:only` 結果だけを入れる
- `digits:` 小数の桁数 (0 から 10)

### 単位変換

```
%%unit to:km 5mi%%           → 5 mi = 8.05 km
%%unit to:c 100F%%           → 100 °F = 37.78 °C
%%unit to:km|m 1.5mi%%
```

長さ、重さ、温度、データ量、時間、体積、速さ、面積に対応しています。尺、合、坪も使えます。

- `to:` 変換先の単位 (必須)。`|` で区切ると複数の単位に変換します
- `digits:` 小数の桁数 (既定は 2)

### 時刻をタイムゾーンで並べる

```
%%time 21:00%%               → 21:00 JST / 12:00 UTC / 04:00 PST / ...
%%time zones:utc|pst 21:00%%
%%time 12/24 21:00%%
%%time now%%
```

入力は `21:00`、`21時30分`、`12/24 21:00`、`2026-12-24 21:00`、`2026年12月24日 21時`、`now` の形で書けます。入力の時刻は、コマンドの設定のタイムゾーン (既定は Asia/Tokyo) として扱います。

- `zones:` 並べるタイムゾーン。`utc`、`jst`、`pst`、`est` などの略称か、`Europe/Paris` のような名前で書きます。省略すると設定の一覧を使います
- `tz:` 入力のタイムゾーンをこのコマンドだけ変える

## 画像を添付するコマンド

### QR コード

```
%%qr https://example.com/slides%%
%%qr hide:on 18時に北口に集合%%
```

中身は本文にも残ります。`hide:on` を付けると、本文と画像の説明から中身を消すので、読み取らないとわからない秘密のメッセージになります。

- `hide:on` 中身を隠す
- `size:` 画像の大きさ (128 から 1024、既定は 512)
- `ecc:` 誤り訂正レベル。`L`、`M` (既定)、`Q`、`H`

### グラフ

```
%%chart.bar labels:月|火|水|木 title:今週のコミット数 3|5|2|8%%
%%chart.line 3|5|2|8/4|1|6|2%%
%%chart.circle labels:ラーメン|カレー|寿司 3|5|2%%
```

`chart.bar` は棒グラフ、`chart.line` は折れ線グラフ、`chart.circle` は円グラフです。値は `|` で区切り、系列を増やすときは `/` で区切ります。値は 60 個、系列は 5 個、円グラフの項目は 12 個までです。

- `labels:` 項目の名前
- `title:` タイトル
- `series:` 系列の名前

オプションの値にはスペースを書けないので、スペースの代わりに `_` を書きます (例: `title:今週_の_結果`)。

### コードと数式と図を画像にする

````
%%img
```ts
const a = 1;
```
%%
````

`%%img ... %%` で囲んだ中のコードブロックをハイライト付きの画像にして添付します。囲んだ中身は本文にそのまま残るので、コードのコピーもできます。

- ```` ```mermaid ```` のコードブロックは Mermaid の図になります
- `\( ... \)` と `\[ ... \]` の数式は、TeX の数式として画像になります
- 50 行を超えるコードは複数の画像に分かれます。100 桁を超える行は途中で切れます
- `theme:dark` ダークテーマにする

Web 版のメニューから使うと、文字を選んでいないときはノート全体を囲みます。

### 統計カード

```
%%stats%%
%%stats lastweek%%
%%stats 30%%
```

期間内の自分のノート数、返信、リノート、もらったリアクションとしたリアクション、よく使ったリアクション、よく動いた時間帯と、日ごとのグラフをカードにします。

期間は `today`、`yesterday`、`week` (既定)、`lastweek`、`month`、`lastmonth`、`year`、`lastyear` か、`30` のような日数 (1 から 366) で書きます。タイムゾーンと週の始まりはコマンドの設定を使います。

## 外部の情報を使うコマンド

### GitHub のコードを引用する

```
%%code https://github.com/owner/repo/blob/main/src/a.ts#L10-L20%%
%%code lines:10|20 owner/repo src/a.ts%%
%%code img:on https://github.com/owner/repo/blob/main/src/a.ts#L10-L20%%
```

GitHub の画面でコピーした URL をそのまま貼れます。指定した行をコードブロックで入れ、元のファイルへのリンクを付けます。ブランチ名で指定しても、リンクはその時点のコミットに固定します。引用できるのは 50 行まで、公開リポジトリだけです。

- `lines:` 行の範囲 (短い書き方のとき)
- `ref:` ブランチやコミット (短い書き方のとき)
- `img:on` ハイライト付きの画像も添付する

### GitHub のコントリビューション

```
%%contrib otnc%%
%%contrib weeks:12 otnc%%
%%contrib%%
```

GitHub ユーザーのコントリビューショングラフを画像にします。ユーザー名を省略すると、コマンドの設定に保存した名前を使います。

- `weeks:` 週数 (4 から 53、既定は 53)

### カード

```
%%card https://github.com/owner/repo/pull/12%%
%%card.gh owner/repo#12%%
%%card.npm galjp%%
%%card https://example.com/article%%
```

GitHub やパッケージ、ページの情報を画像にして、リンクと一緒に入れます。`%%card URL%%` は URL から種類を判定します。

| 書き方 | 対象 | 短い書き方の例 |
| --- | --- | --- |
| `card.gh` | GitHub のリポジトリ、Issue、PR、コミット、リリース、Discussion、ユーザー、Gist | `owner/repo`、`owner/repo#12`、`owner/repo@abc1234`、`otnc` |
| `card.npm` | npm のパッケージ | `galjp` |
| `card.pypi` | PyPI のパッケージ | `requests` |
| `card.crates` | crates.io のクレート | `serde` |
| `card.docker` | Docker Hub のイメージ | `redis`、`library/redis` |
| `card.ogp` | そのほかのページ | URL |

- `style:ogp` サイトが公開しているプレビュー画像を使う。GitHub とそのほかのページの既定
- `style:card` 取ってきた情報から、このサーバーでカードを作る。パッケージの既定

画像は取得した時点の情報なので、カードには取得日が入ります。

### Spotify で再生中の曲

```
%%np%%
%%np link:off%%
%%np format:short%%
```

Spotify でいま再生している曲に置き換えます。何も再生していないときは投稿できません。既定の形式は [SpotifyNowPlaying](https://github.com/otnc/SpotifyNowPlaying) の共有と同じで、次のようになります。

```
#NowPlaying
曲名 - アーティスト
https://open.spotify.com/track/...
```

先に、Web 版の投稿フォームのメニューにある Spotify 連携の項目から連携してください。新しいタブで Spotify の画面が開き、許可すると完了のメッセージが出ます。連携の解除も同じ項目からできます。

- `link:off` 曲の URL を付けない
- `format:full` `🎵 曲名 - アーティスト (アルバム)` の 1 行にする
- `format:short` `🎵 曲名 - アーティスト` の 1 行にする

## コマンドの設定

Web 版の投稿フォームのメニューにある設定の項目で、次の値を保存できます。保存した値は、ほかのクライアントから投稿したときにも使われます。

| 項目 | 使うコマンド | 既定値 |
| --- | --- | --- |
| タイムゾーン | `time`、`stats`、`card` | Asia/Tokyo |
| `time` で並べるタイムゾーン | `time` | UTC、America/Los_Angeles、America/New_York、Europe/London |
| 週の始まり | `stats` | 月曜日 |
| GitHub のユーザー名 | `contrib` | なし |
